# Café Origen — Carrito de compras

## Propósito
Carrito de compras para una cafetería. Permite agregar y eliminar productos, aumentar o disminuir su cantidad, calcular el total de la compra y aplicar el código de descuento DESCUENTO10 una sola vez. Es el proyecto de la Práctica 3 del Laboratorio de Programación Web, con sus errores de lógica ya corregidos.
